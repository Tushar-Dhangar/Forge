# Forge Hardening Guide

## Purpose

This records each hardening change applied to the environment and the
re-attack result that proves it worked. It's written from the completed work
so the hardening can be reviewed or reproduced without relying on chat history.

[ADR-002](../engineering-decisions/002-validation-by-reattack.md), and this
guide gets filled in as each fix is applied and validated.
